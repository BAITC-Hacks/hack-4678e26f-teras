⚡ Быстрый старт

Требования

- Docker 24+ и Docker Compose
- (опционально) Node 20+ / Python 3.11+ для локального запуска без Docker

Запуск одной командой

git clone https://github.com/BAITC-Hacks/hack-4678e26f-teras.git
cd hack-4678e26f-teras
cp .env.example .env
docker compose up --build

Откроется на http://localhost:3000, API — на http://localhost:8000/docs.

<details>
<summary><b>Локальный запуск без Docker</b></summary>

# backend
cd backend && pip install -r requirements.txt && uvicorn app.main:app --reload

# frontend
cd frontend && npm ci && npm run dev

</details>
